# Code map

_Generated by `python scripts/gen_codemap.py`. Do not edit by hand._

## Backend (Python)

### `backend/app/agent/graph.py`

The Aria agent as a LangGraph state machine.

- `async classify_intent(llm: LLMProvider, history: list[dict], query: str) -> str` - Router step. Falls back to 'chitchat' if the model cannot produce a valid intent.
- `async decide_offer(llm: LLMProvider, history: list[dict]) -> str` - Proactive step. Returns 'restaurants', 'summary' or 'none'.
- `build_graph(deps: AgentDeps)` - Compile the agent. Returns a LangGraph app; invoke with a thread_id in the config.

### `backend/app/agent/prompts.py`

Prompts and JSON schemas for every agent step.

- `transcript(history: list[dict], n: int) -> str` - Render the last n messages as 'name: text' lines.
- `to_chat_messages(history: list[dict], n: int=12) -> list[ChatMessage]` - Convert stored history dicts into provider ChatMessages (with the system prompt).

### `backend/app/agent/service.py`

Glue between the chat room and the LangGraph agent.

- **class `AriaService`**
  - `spawn(self, coro: Coroutine[Any, Any, None]) -> asyncio.Task`
  - `async wait_idle(self) -> None` - Wait for in-flight work (used by tests).
  - `async on_human_message(self, msg: Message) -> None` - Called after every human message has been added to the room.
  - `async handle_confirm(self, action_id: str, approve: bool, user: str) -> None`

### `backend/app/agent/state.py`

State carried through the LangGraph agent. Plain dicts only, so it can be checkpointed.

- **class `AgentState(TypedDict)`**
- **class `AgentDeps`** - Everything a node may need. Injected, never imported, so tests can fake it.

### `backend/app/chat/mentions.py`

Detect and strip @Aria mentions.

- `is_mention(text: str) -> bool` - True for '@Aria hi' but not for 'bob@aria.com' or '@ariana'.
- `strip_mention(text: str) -> str`

### `backend/app/chat/room.py`

The chat room: connected users, message history, broadcasting, persistence.

- **class `Message`**
- **class `Room`**
  - `async load(self) -> None` - Restore recent history from SQLite (call once at startup).
  - `users(self) -> list[str]`
  - `name_taken(self, name: str) -> bool`
  - `async join(self, name: str, ws: WebSocket) -> None`
  - `async leave(self, name: str) -> None`
  - `async add(self, msg: Message) -> None` - Append, persist (system notices are not persisted) and broadcast.
  - `async update_card(self, message_id: str, patch: dict[str, Any]) -> None` - Merge `patch` into a message's card and tell every client.
  - `async broadcast_presence(self) -> None`
  - `async set_typing(self, who: str, on: bool) -> None`
  - `async broadcast(self, event: dict[str, Any]) -> None`

### `backend/app/ingest/chunker.py`

Split page text into overlapping chunks suitable for embedding.

- `chunk_id(source: str, page: int | None, index: int) -> str` - Deterministic id so re-uploading the same file overwrites instead of duplicating.
- `chunk_pages(pages: list[PageText], source: str, *, kind: str='text', size: int=CHUNK_SIZE, overlap: int=CHUNK_OVERLAP) -> list[Chunk]`

### `backend/app/ingest/loaders.py`

Turn uploaded bytes into page-level text. No chunking and no embedding here.

- **class `PageText`**
- **class `UnsupportedFileError(ValueError)`**
- `detect_kind(filename: str) -> Kind` - Classify an upload by extension. Raises UnsupportedFileError otherwise.
- `image_mime(filename: str) -> str`
- `load_pdf(data: bytes) -> list[PageText]` - Extract text per page. Scanned PDFs with no text layer yield no pages.
- `load_text(data: bytes) -> list[PageText]`

### `backend/app/ingest/pipeline.py`

Upload -> text -> chunks -> embeddings -> vector store (+ a row in SQLite).

- `safe_name(filename: str) -> str` - Strip any directory part so uploads cannot escape the upload dir.
- `async build_chunks(llm: LLMProvider, filename: str, kind: Kind, data: bytes) -> list[Chunk]` - Extract text (or a caption for images) and split it into Chunks.
- `async embed_and_store(llm: LLMProvider, store: VectorStore, chunks: list[Chunk], *, recreate: bool=False) -> None` - Embed in small batches (8 GB machines) and write to the vector store.
- `async ingest_file(*, llm: LLMProvider, store: VectorStore, db: Database, settings: Settings, filename: str, data: bytes, uploaded_by: str) -> DocumentRow`
- `async reindex_all(*, llm: LLMProvider, store: VectorStore, db: Database, settings: Settings) -> int` - Recreate the index and re-embed every stored upload.

### `backend/app/providers/base.py`

Provider interfaces. The agent and API layers depend ONLY on these.

- **class `ChatMessage`**
- **class `ToolSpec`** - Tool description in JSON-schema form (OpenAI-style function spec).
- **class `ToolCall`**
- **class `LLMResult`**
- **class `Chunk`**
- **class `SearchHit`**
- **class `LLMProvider(ABC)`** - Chat, structured output, embeddings, and image captioning.

  - `async structured(self, messages: list[ChatMessage], schema: dict[str, Any]) -> dict[str, Any]` - Return a dict that validates against `schema`.
  - `async embed(self, texts: list[str], *, is_query: bool) -> list[list[float]]` - Embed texts. Providers that need task prefixes (nomic) add them here.
  - `async caption_image(self, image_bytes: bytes, mime_type: str) -> str` - Describe the image and transcribe any visible text.
- **class `VectorStore(ABC)`**
  - `async ensure_index(self, dim: int, *, recreate: bool=False) -> None` - Create the index for `dim`-dimensional vectors. Recreate on dim change.
  - `async upsert(self, chunks: list[Chunk], vectors: list[list[float]]) -> None`
  - `async search(self, vector: list[float], k: int=4) -> list[SearchHit]`
  - `async delete_source(self, source: str) -> None`
- **class `SecretsProvider(ABC)`**
  - `get(self, name: str) -> str` - Return the secret or raise KeyError.
